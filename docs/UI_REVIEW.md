## 本次实际观察

暂停弹层关闭入口、滚动选项和底部固定确认按钮已观察；只读确认禁用。现存七张本机检查图位于忽略的 .impeccable/review/installerx-*.jpg，未随公开源码或安装包分发。未取得可靠的宽屏最终截图，不将手机图标为桌面证据。

## 状态与保护

- 首页未知时不显示有效统计；安全旁路、核心运行和接管覆盖分别说明，IPv6 放行仍标明不完整。
- 写入继续受设备授权与 busy 约束；读取设置失败时不允许保存默认空草稿；保存 DNS 保留当前预设。
- 外观只保存在当前 origin 的浏览器 localStorage，不改变 DNS 配置或授权。详情隐藏底栏，history 返回实际来源。
- 进入动效18dp／240ms，遵循 prefers-reduced-motion。
- 导入／恢复仍需确认，改密成功后退出。连接恢复后清除连接错误，操作通知3.5秒后清除。
- 日志区分无查询、无匹配结果、加载和错误；旧请求取消和请求编号保护保留。
- 原有19个API端点集合未变。本次 UI 调整未修改后端。

## 构建和复核

新增 preference 依赖的校验输入经发布元数据核对。最终离线 jsBrowserDistribution 构建成功。独立整套手机页面审阅提出唯一浅色警示正文对比度P2；修复、重拍后 verdict 为 ship，仅表示该修复解除。detector 曾对 Kotlin 源码返回0条，其非HTML正则覆盖不能代替Compose布局、对比度或无障碍验收。
